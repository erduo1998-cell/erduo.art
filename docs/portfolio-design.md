# 耳朵个人网站 · 2026-09-07

用户要求以 moncy.dev 为视觉和交互参考，并授权整理本地业务与项目、制作必要图片和视频、更新 erduo.art。

## 设计

- 叙事：个人 → 判断方式 → 合作方向 → 作品与项目 → 知识资产 → 联系。
- 黑底 #000000、雾白 #eae5ec、淡紫 #c2a4ff，边界 #363136。紫光只出现在人物轮廓、两侧光场和重点词。
- 展示标题使用官方 Fontshare CDN 的 Clash Display；正文使用本地 Geist 与 Noto Sans SC，原子页保留 Kanit。
- 桌面首屏中央人物，左右身份大字；第一屏到 About 使用共同 sticky 容器，人物随滚动左移。移动端按文档流重新排布。
- 8 px 基础间距，桌面内容区留出固定社交栏；作品区横向展览、交替图文，触屏原生横向滚动。
- 700 ms 渐入，200 ms 微交互；支持 reduced-motion、全局动效开关、键盘和无 JavaScript 阅读。

## 内容与资产

- 网站对外称呼为耳朵 / 刘冉，品牌 SURGE / 无限涌动。年限统一十余年，不沿用 11 / 12 年冲突口径。
- 人物参考使用本人提供的黑色 Polo 肖像，保留五官、成年脸型和身材比例；新人物是 AI 生成的风格化视觉，不替代真实照片。
- 新图由 Codex 内置 imagegen 生成：assets/portfolio/erduo-avatar.webp、erduo-workstation.webp。完整提示词和执行记录留在本地生图项目，不公开私人工作路径。
- 不借用参考网站的人物、作品、履历或第三方品牌素材。
- 项目成熟度以 2026-09-07 本人公开 GitHub 资料为准；没有验证的产品效果不作承诺。
- 保留 /reachsurge/ 与 /knowledge/ 正式入口及已有静态部署。
